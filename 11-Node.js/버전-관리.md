# 버전-관리

> 대분류: `11-Node.js` / Node.js 버전 갈아끼우기

### nvm
**개요:** Node 버전을 여러 개 깔고 갈아끼우는 관리자다. `~/.nvm` 네 홈 안에 산다.
**작동 방식:** `nvm install <버전>`을 치면 해당 Node 바이너리를 `~/.nvm/versions/node/` 밑에 내려받는다. `nvm use <버전>`을 치면 셸의 PATH를 그 버전 쪽으로 바꿔서 `node` 명령이 가리키는 실체를 바꾼다. 폴더마다 `.nvmrc` 파일을 두면 버전을 고정할 수 있다.
```bash
nvm --version
nvm install --lts
nvm use 20
node --version
```
