# 실행·패키지

> 대분류: `11-Node` / 자바스크립트 실행과 패키지 관리 (07-Python의 실행-패키지에 대응)

### node
**개요:** 자바스크립트를 브라우저 밖에서 실행하는 본체다. Python의 `python3`에 해당한다.
**작동 방식:** 입력된 JS 파일을 V8 엔진으로 읽어 위에서 아래로 실행한다. `require`·`import`를 만나면 `node_modules`와 내장 모듈에서 해당 부품을 찾는다. 인수가 없으면 대화형 프롬프트(REPL)가 열려서 바로 실험할 수 있다.
```bash
node --version
node hello.js
```

### npm
**개요:** JS 부품(패키지) 설치기다. Python의 `pip3`에 해당한다.
**작동 방식:** `npm install <이름>`을 치면 레지스트리(registry.npmjs.org)에서 해당 패키지와 의존성을 함께 받아온다. `package.json`에 기록하고 `node_modules/`에 저장한다. Node에 동봉되어 별도 설치가 필요 없다.
```bash
npm --version
npm install express
```

### npx
**개요:** 설치 없이 패키지 명령을 한 번 실행하는 러너다. npm에 동봉되어 있다.
**작동 방식:** 패키지명을 받으면 캐시나 레지스트리에서 해당 명령을 찾아 임시로 받아 실행한다. `node_modules`를 오염시키지 않는다. 일회성 도구(프로젝트 생성기 등)를 쓸 때 편하다.
```bash
npx --version
npx create-next-app my-app
```
