## 소분류 규칙 (파일 = 한 개념)

- 새 주제는 대분류 폴더 안에 소분류 `.md`로 추가한다.
- 대분류가 없으면 `번호-이름/` 폴더를 새로 만든다 (예: `11-Node/`).
- 도구 문서는 `### 도구명` → 개요 → 작동 방식 → 예시 순으로 쓴다.
- 읽기 전용 조사(04)와 가공·편집(02-바이너리편집)은 섞지 않는다.
